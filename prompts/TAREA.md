# Tarea: Mi prompt profesional

## Funcionalidad elegida

CRUD de productos para una aplicación de tienda desarrollada en Java Swing.

## Version 1: prompt basico

Crea un CRUD de productos en Java.

## Version 2

Actua como desarrollador Java. Crea un CRUD de productos para una tienda usando Java Swing. Cada producto debe tener codigo, nombre, precio y stock. El sistema debe permitir registrar, mostrar, actualizar y eliminar productos.

## Version 3: prompt final

Actua como desarrollador Java especializado en aplicaciones de escritorio.

Crea un ejemplo sencillo de un CRUD de productos para una tienda utilizando Java Swing. Cada producto debe tener codigo, nombre, precio y stock. El usuario debe poder registrar, mostrar, actualizar y eliminar productos.

Organiza el programa usando una clase Producto, una clase para la interfaz y una clase principal.

Usa este estilo para los metodos de la clase Producto: getPrecio() y setPrecio(double precio).

Explica brevemente la estructura del programa y despues presenta el codigo separado por clases.

No uses librerias externas.

## Componentes del prompt final

| Componente | Texto utilizado |
|---|---|
| Rol | Actua como desarrollador Java especializado en aplicaciones de escritorio. |
| Instruccion | Crea un ejemplo sencillo de un CRUD de productos. |
| Contexto | Es para una tienda, usa Java Swing y los productos tienen codigo, nombre, precio y stock. |
| Ejemplo | Usa este estilo para los metodos: getPrecio() y setPrecio(double precio). |
| Formato | Explica primero la estructura y despues presenta el codigo separado por clases. |

| ¿Utiliza Java Swing? | Si |

## Errores que evite

**1. Ser demasiado general:**  
En la version 1 solo pedi un CRUD de productos. Lo evite agregando el lenguaje, la tecnologia, los atributos y las funciones necesarias.

**2. No indicar el formato:**  
En las primeras versiones no indique como queria recibir la respuesta. En el prompt final pedi una explicacion breve y el codigo separado por clases.
